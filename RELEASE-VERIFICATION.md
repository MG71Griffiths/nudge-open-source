# Source release verification — 0.1.1 (45)

Prepared on 22 October 2026. This source snapshot is separate from App Store approval, TestFlight distribution and hosted services. Build45 extends passwordless onboarding with personal details, activity, goals and a target review before optional ChatGPT setup. Measurements accept cm or feet/inches and kg or stone/pounds while retaining exact canonical values through display conversions.

Known nutrition targets stay visible when intake is unlogged or unknown. Missing targets carry an explanation rather than an invented value. A narrowly gated native startup repair fills eligible missing automatic targets using existing rules; explicit manual clears, custom targets, clinical context and past dated targets remain protected. The existing nutrition formulas have not changed. No particular TestFlight reporter's missing profile field is inferred from this source review.

The Native/Web source matches the reviewed frozen build45 inputs apart from the established independent-service, website and example-identity substitutions. The backend defaults to a reserved .invalid hostname, the app identifier is an example and no signing team is supplied. Original operator tenants, credentials, private records, screenshots, diagnostics, provisioning material and development Git history are excluded.

The ordinary account flow remains email plus a six-digit code. Provider email length, SMTP and actual delivery must be configured and verified independently. No fixed code, bypass account or shared reviewer password is included. Existing-password access remains separately available for App Review.

MIT, third-party notices, dataset attribution and artwork provenance are preserved from public build44. Known-pattern privacy scanning is bounded and does not prove arbitrary sensitive content can never exist. Live provider login, a fork's account lifecycle, cloud deployment and real-device behaviour require separate validation. Parsing native source or executing Foundation helpers is not a full native build or on-device UI test.

Photo analysis remains an estimate. Some real scans have exceeded the ten-second target; this release does not guarantee timing, measured nutrient accuracy or recognition of every photograph. Mixed subjects may need a clearer selection of the intended food.
